# 社員プロフィールデータベース

シード・プランニング全社員用の社員プロフィールデータベースシステムです。

## 機能

- **プロフィール一覧・検索**: 全社員のプロフィールを閲覧、検索
- **フィルタリング**: 担当分野、役職、所属でフィルタリング
- **詳細表示**: 各社員の詳細情報を表示
- **登録・編集**: プロフィールの新規登録と編集
- **削除**: プロフィールの削除

## プロフィール情報

各プロフィールには以下の情報が含まれます：

- 社員番号
- 氏名
- 所属
- 役職
- 担当分野（複数選択可）
  - エネルギー・環境
  - エレクトロニクス・IT
  - その他の市場分野
  - ヘルスケア
  - メディカル・バイオ
  - 医療IT
- 入社年
- 略歴
- 最近のプロジェクト
- プロジェクトでの役割
- 自由記述

## 使い方

1. `people/index.html` を開く
2. 検索バーで社員を検索、またはフィルターで絞り込み
3. プロフィールカードをクリックして詳細表示
4. 「新規登録」ボタンから新しいプロフィールを追加
5. 詳細ページから編集・削除が可能

## 技術仕様

- **フロントエンド**: HTML, CSS, JavaScript (Vanilla JS)
- **データ保存**: LocalStorage
- **レスポンシブ対応**: モバイル・タブレット・デスクトップ
- **デザイン**: シード・プランニングの配色（ブラウン/ベージュ/オレンジ）
