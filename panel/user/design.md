# Dパネル マイページ — カラー指定デザインガイド

> 医師が「迷わない・疲れない・不安にならない」ための静かで誠実な配色・トーンの定義

---

## 1. デザインアイデンティティとカラーパレット

### コンセプト

- 余白重視、静かで誠実な医療向け UI
- 低彩度の配色による信頼感の醸成
- 感情を揺さぶる「派手な演出」の徹底排除
- ポイント表示は煽らず、誠実な情報として扱う

### カラースウォッチ

| 名称 | カラーコード | 用途 |
|------|-----------|------|
| プライマリネイビー | `#243A52` | 信頼・安定の主役色 |
| サイドバーネイビー | `#334B60` | 構造を分ける補助色 |
| アクショングリーン | `#5F8475` | 行動を示す強調色 |
| メインテキスト | `#2B2F33` | 可読性の基準色 |
| 背景 | `#F5F6F7` | ページ背景 |
| 枠線 | `#E6E8EB` | カード・テーブルの罫線 |

### 共通実装ルール

| 項目 | 仕様 |
|------|------|
| フォント | Noto Sans JP |
| アイコン | 細線 SVG のみ |
| 主要ボタン | `#5F8475` |
| セカンダリボタン | `#E6E8EB` |
| ホバー | `0.2s ease-in-out` / `#567A6C` |
| レスポンシブ境界 | `768px` |

## 2. ダッシュボードとレイアウト仕様（PC）

> 黄金比に基づいたサイドバーレイアウトと、医師の視線誘導を考慮した情報の優先順位

PC版は「調査開始」を唯一の行動色にし、残高や履歴は落ち着いた中立色で整理する。

### レイアウト寸法

| 要素 | サイズ | 備考 |
|------|--------|------|
| ヘッダー | 72px | 検索・通知・アカウントを上部固定バーに集約 |
| サイドバー | 260px | 左固定ナビで情報構造を分離し、迷いを防止 |
| 余白 | 32–40px | 白場を十分に確保し、圧迫感を抑える |

### 情報優先度

1. **参加可能な調査** — 参加可能な案件を上段配置し、最初の視線をここへ集約
2. **ポイント** — 確定済み残高として表示
3. **履歴** — 直近3件のプレビューを下段に配置

### カード・影の仕様

| 項目 | 仕様 |
|------|------|
| カード角丸 | `8–10px` |
| 影 | `rgba(0, 0, 0, 0.05)` を基準に、画面印象は静かに保つ |
| ポイント残高 | ネイビー `#243A52` / `32px`。残高はサイズ差で認識させ、緑は使わない |

### サイドバー ナビゲーション項目

- ホーム
- 調査一覧
- ポイント
- 履歴
- サポート

### 調査カード表示

各調査は以下の情報を1カード内に表示する：

- 調査タイトル（太字）
- 所要時間 / 獲得ポイント
- アクションボタン（最上位のみ「開始」=アクショングリーン、それ以外は「確認」=中立色）

## 3. ポイント履歴とステータスバッジ

> ポイント履歴の透明性を高める、低彩度なステータスラベルの運用ルール

履歴画面では「何が起きたか・何ptか・確定したか」を過不足なく並列表示する。

### 履歴テーブル構成

| カラム | 説明 |
|--------|------|
| 日付 | `YYYY/MM/DD` 形式 |
| 内容 | 調査名・事務局作業名 |
| 種別 | ウェブ調査 / 座談会 / 事務局 |
| pt | `+1,200` / `-300` などの増減表示 |
| 状態 | ステータスバッジで表示 |

### ステータスバッジ仕様

| ステータス | 背景色 | 文字色 |
|-----------|--------|--------|
| **完了**（完了謝礼） | `#E8F5E9`（薄緑） | `#4F7A6D` |
| **調整** | `#FFFDE7`（薄黄） | `#2B2F33` |
| **確定待ち** | `#E3F2FD`（薄青） | `#2B2F33` |

### 運用ルール

- 透明性＝信頼：履歴は詳細かつ正確に表示
- ステータス別の背景色を上記テーブルのとおり定義
- 負の値は赤ベタ塗りにせず、数量情報として静かに表示

## 4. レスポンシブ対応と禁止事項

> モバイル環境での操作性確保と、ブランド毀損を防ぐ禁止事項の徹底

静かな医療 UI を維持するため、警告・例外表現も落ち着いたトーンで統一する。

### モバイル対応仕様

| 項目 | 仕様 |
|------|------|
| ブレークポイント | `768px` 以下でモバイルレイアウトへ切替 |
| サイドバー | ドロワー化（ハンバーガーメニュー） |
| タップ領域 | 最低 `44×44px` |

### 禁止事項

| ❌ 禁止 | 理由 |
|---------|------|
| **絵文字** | 軽さが先に立ち、医療文脈の信頼感を崩す |
| **強いグラデーション** | 背景の主張が強すぎ、情報の優先順位が曖昧になる |
| **光沢・影過多** | 立体感が過剰になり、業務 UI では装飾的に見える |
| **赤いベタ塗りエラー** | 刺激が強く不安を増幅するため、静かな通知へ置換する |

### 推奨エラー・警告表現

警告は**淡い枠線＋簡潔な文言**で静かに通知する。
